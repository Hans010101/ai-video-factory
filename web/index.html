⚠️ 关于本站与渲染能力的说明

本站是 AI 视频工厂的项目主页与文档站，部署在 Cloudflare Pages 上，可随时云端访问。

视频渲染引擎不在本站运行。本项目的核心是 Python + FFmpeg + Remotion 工具链，需要本地文件系统、长时间 CPU/GPU 计算和完整的多媒体依赖 —— 这些都超出了 Cloudflare Workers/Pages 边缘运行时的能力范围。

实际生产视频请按下方本地部署指南在你自己的电脑或服务器上运行 make setup。

本地部署指南

视频渲染需要本地环境。以下步骤在 macOS / Linux / Windows 上均可运行。

  1. 安装必备环境

    Python 3.10+ · FFmpeg · Node.js 18+ · 一款 AI 编程助手（Claude Code、Cursor、Copilot、Windsurf 或 Codex）

    # macOS
brew install python ffmpeg node

# Ubuntu / Debian
sudo apt install python3 python3-venv ffmpeg nodejs npm

  2. 克隆并初始化

    一条 make setup 会创建虚拟环境、安装依赖、装好 Remotion 与 Piper TTS。

    git clone https://github.com/Hans010101/ai-video-factory.git
cd ai-video-factory
make setup

  3. 配置 API 密钥（可选）

    密钥越多可用工具越多，但不配也能用零密钥路径出片。

    cp .env.example .env
# 按需填入 OpenAI / Google / ElevenLabs 等密钥

  4. 用自然语言下单

    在 AI 编程助手中打开这个项目目录，直接说出你要的视频。

    "制作一个 60 秒的动画解说视频，讲解神经网络是如何学习的"

"制作一部 75 秒的纪录片蒙太奇，展现雨中的城市生活。
 只使用真实素材，无旁白，需要挽歌般的基调和配乐。"

  5. 取片

    成片输出到 projects/<项目名>/renders/final.mp4，全程带决策日志与成本快照。
